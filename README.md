## Audit-Ready Collections System

A secure collections management system with 6-year retention & Archive-only logic (No Deletion).

### Tech Stack - Frontend + Backend
- Frontend: Next.js 14 + Tailwind CSS (Clients UI)
- Backend: Next.js API Routes + Prisma ORM
- Database: Supabase PostgreSQL
- Security: Row Level Security (RLS) Enabled
